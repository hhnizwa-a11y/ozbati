# عزبتي | Ozbati — كل بيسة محسوبة

تطبيق ويب لإدارة المصاريف الشخصية والعائلية بالريال العُماني، بواجهة عربية RTL، يعمل محليًا دون تسجيل دخول.

## التثبيت على أندرويد

- **ملف APK:** من صفحة [الإصدارات](../../releases/latest) حمّل `ozbati.apk` على هاتفك وافتحه، ووافق على «التثبيت من مصادر غير معروفة».
- **أو كتطبيق ويب:** افتح موقع المشروع على GitHub Pages في Chrome، ثم القائمة ⋮ ← «إضافة إلى الشاشة الرئيسية» / «تثبيت التطبيق».

كل مستخدم يكتب اسمه وأسماء أطفاله وسياراته في شاشة الترحيب الأولى، ويمكنه تغييرها من الإعدادات. البيانات تبقى على جهاز كل مستخدم فقط.

## البناء الآلي

عند كل رفع إلى الفرع `main` يشغّل GitHub Actions (`.github/workflows/build.yml`):
1. الاختبارات وفحص الأنواع.
2. نشر نسخة الويب (PWA) على GitHub Pages.
3. بناء APK ونشره في صفحة الإصدارات.

لتوقيع APK بمفتاح ثابت (ضروري لتحديث التطبيق دون حذفه)، أضف في Settings ← Secrets and variables ← Actions:
- `OZBATI_KEYSTORE_BASE64`: ملف المفتاح بترميز base64
- `OZBATI_KEYSTORE_PASSWORD`: كلمة مروره

دون هذين السرّين يُبنى إصدار تجريبي (debug).

## التشغيل

```bash
npm install
npm run dev          # بيئة التطوير
npm test             # اختبارات محرك الاستيراد
npx cap sync android # مزامنة نسخة الويب مع مشروع أندرويد (بعد npm run build)
npm run build        # نسخة PWA في dist/ للاستضافة على أي خادم HTTPS
npm run build:single # ملف HTML واحد مستقل في dist-single/
```

## البنية

```
src/
  lib/
    types.ts        نماذج البيانات (المبالغ بالبيسة كأعداد صحيحة)
    money.ts        تحويل الأرقام العربية، التحليل الدقيق للمبالغ، التنسيق 59.000 ر.ع
    text.ts         توحيد النص العربي للمطابقة
    defaults.ts     التصنيفات والسيارات والاشتراكات الافتراضية
    classifier.ts   التصنيف بالكلمات الدالة + التعلم من التصحيحات + اكتشاف السيارة والاشتراك
    parser.ts       محرك استيراد واتساب (iOS/أندرويد، العناوين، التكرار، القيم غير المعتادة)
    metrics.ts      الدوال المركزية لكل المؤشرات والرسومات والتقارير
    insights.ts     المحلل المالي المحلي + واجهة AnalysisProvider لربط Gemini/Claude لاحقًا
    db.ts           IndexedDB (8 جداول بعلاقات) مع بديل في الذاكرة
    files.ts        CSV / XLSX / PDF (A4 بخط عربي متصل) / النسخ الاحتياطي والتحقق منه
    sync.ts         نقطة الربط المستقبلية مع Firebase Auth + Firestore
  store/            الحالة العامة والإجراءات (AppContext) والخطافات
  components/       التخطيط، الرسومات (Recharts)، محرر العمليات، عناصر الواجهة
  pages/            الرئيسية، العمليات، الاستيراد، التحليل، الميزانيات، السيارات،
                    الاشتراكات، التقارير، المحلل المالي، العزب الشهرية، الإعدادات
android/            مشروع أندرويد (Capacitor)
tests/              اختبارات Vitest على المحادثة النموذجية
```

## قواعد مالية

- كل مبلغ يُخزَّن بالبيسة (1 ر.ع = 1000 بيسة) ويُعرض بثلاث منازل عشرية.
- «التحويل بين حساباتي» لا يدخل في إجمالي المصاريف؛ «مبلغ مرسل لشخص آخر» يدخل.
- الاشتراك المجدول لا يُحتسب إلا عند تسجيل دفعة فعلية.
- المؤشرات التي تحتاج ميزانية أو دخلًا لا تُحسب قبل إدخالهما.
- تاريخ العملية مستقل عن الشهر المالي (العزبة) الذي تنتمي إليه.
